# Compliance Standards Research Lane

This directory stores source-rights and manual-intake evidence for possible
standards-derived Make linter candidates.

## Boundary

The compliance lane is advisory metadata only. It may preserve source metadata,
rights posture, bibliography notice pointers, local predicate notes, and
manual-intake decisions. It must not copy licensed standard text, claim
certification, assert legal sufficiency, or activate runtime linter behavior
without a separate promoted rule task.

## Promotion Rule

A standards-derived idea may become active behavior only after it has a
deterministic local predicate, passing and failing fixture plans, a supported
canonical rule code, and client-safe output wording that avoids compliance,
certification, audit, attestation, or legal-advice claims.

The current source-rights ledger requires a per-standard bibliography notice,
an official source URL, an official terms or rights URL, a profile gate, and an
explicit `runtime_activation_allowed: false` marker before any future promotion
work can consider the source.
